Shared UX decisions (all six designs)

  • No sign-up link — accounts are by invitation only (security.md §3).
  • One generic error for a wrong email or password; never says whether the account exists. Mentions the lockout pause.
  • MFA step: one numeric field with autocomplete="one-time-code", a recovery-code link, and a way back.
  • The sign-in page shows no real data — the illustrations are generic.
  • Status badges always carry a text label (Reserved / Confirmed / Live), so colour is never the only signal.
  • Navigation groups: work (Overview, Calendar, Practices, Migrations, Tasks, Templates) · Records (Audit log, Reports) · Administration. Admin items would be hidden for users without the permission.
  • User menu: Profile, two-step sign-in status, Sign out everywhere, Sign out. Times are labelled as NZ time.
